# 电商提示词收藏

专注于电商场景的 GPT Image 2 提示词集合，涵盖商品主图、详情页、包装设计、模特展示等电商视觉内容创作。

**总计**: 1,508 条电商提示词  
**精选展示**: 30 条（分布在本目录各子文件夹中）  
**完整数据集**: `data/ecommerce/gpt-image-2.jsonl`

## 🗂️ 使用方式

### 1. 浏览精选示例

本目录按场景分类存放 **30 个精选提示词**，每个 Markdown 文件包含：

- 完整提示词文本
- 中英文标题和描述
- 适用场景标签
- 来源和许可信息

直接打开对应分类文件夹，选择需要的提示词复制使用。

### 2. 使用完整数据集

完整的 1,508 条提示词存储在 JSONL 格式：

```bash
data/ecommerce/gpt-image-2.jsonl
```

每行一个 JSON 对象，包含字段：

- `id` — 唯一标识
- `title` — 提示词标题
- `content` — 完整提示词文本
- `description` — 用途说明
- `model` — 模型名称（gpt-image-2）
- `category` — 分类（电商）
- `bucket` — 子分类（主图/包装/详情页等）
- `source_repo` — 来源仓库
- `source_url` — 来源链接
- `source_license` — 原始许可
- `needs_reference` — 是否需要参考图

### 3. 按需筛选

可以通过命令行工具快速筛选：

```bash
# 查看所有主图提示词
jq 'select(.bucket=="主图")' data/ecommerce/gpt-image-2.jsonl

# 提取需要参考图的提示词
jq 'select(.needs_reference==true)' data/ecommerce/gpt-image-2.jsonl

# 统计各分类数量
jq -r '.bucket' data/ecommerce/gpt-image-2.jsonl | sort | uniq -c
```

## 🔗 数据来源

所有电商提示词来自以下开源项目：

### 1. YouMind-OpenLab/gpt-image-2-prompts-search

- **许可**: CC BY 4.0
- **来源文件**: 
  - `references/ecommerce-main-image.json` (452 条)
  - `references/product-marketing.json` (1056 条电商相关)
- **链接**: https://github.com/YouMind-OpenLab/gpt-image-2-prompts-search

**数据处理**：
- 提取 `ecommerce-main-image.json` 全部 452 条
- 从 `product-marketing.json` 过滤出明确的电商场景（主图、详情页、包装、上身、店铺等关键词）
- 按 ID 去重，避免重复收录
- 根据内容关键词自动分类到 6 个子桶
